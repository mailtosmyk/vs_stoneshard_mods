[b]  Description[/b]



&lt;br /&gt;



&lt;br /&gt;Necromancy adds a full occult skill school to Stoneshard. Raise skeletons and thralls, curse enemies with Withering Curse, drain essence from the dead, and bind unholy power across a 14-skill tree (11 active, 3 passive).



&lt;br /&gt;



&lt;br /&gt;Built for ModShardLauncher Enhanced and Stoneshard 0.9.4.x.



&lt;br /&gt;



&lt;br /&gt;Play a dark mage who turns corpses into weapons — bolt, blight, blast, and army.



&lt;br /&gt;



&lt;br /&gt;────────────────────────────────────────



&lt;br /&gt;



&lt;br /&gt;[b]  Installation instructions[/b]



&lt;br /&gt;



&lt;br /&gt;1. Switch Stoneshard to the modbranch beta on Steam (Properties → Betas → modbranch). The version in-game should end with -vm.



&lt;br /&gt;



&lt;br /&gt;2. Install ModShardLauncher Enhanced from Nexus (https://www.nexusmods.com/stoneshard/mods/103), or upstream MSL from GitHub (https://github.com/ModShardTeam/ModShardLauncher/releases) / Nexus (https://www.nexusmods.com/stoneshard/mods/29). Follow the official install guide (https://modshardteam.github.io/ModShardLauncher/guides/how-to-play-mod.html).



&lt;br /&gt;



&lt;br /&gt;3. In your Stoneshard folder, rename data.win to vanilla.win (backup first).



&lt;br /&gt;



&lt;br /&gt;4. Download this mod’s .sml file and place it in MSL’s Mods folder.



&lt;br /&gt;



&lt;br /&gt;5. Open MSL → Anvil (Mods) → load vanilla.win → enable Necromancy → Save as e.g. modded.win.



&lt;br /&gt;



&lt;br /&gt;6. Launch Stoneshard and select modded.win.



&lt;br /&gt;



&lt;br /&gt;Tip: Back up your saves before using mods. If MSL appears frozen while loading the .win, wait — that is normal.

&lt;br /&gt;[b]  Main features[/b]



&lt;br /&gt;



&lt;br /&gt;• New skill school: Necromancy — 14 skills across 4 tiers



&lt;br /&gt;



&lt;br /&gt;• Summoning — Summon Skeleton, Resurrection, Wraith Summoning; thralls scale with Willpower and passives



&lt;br /&gt;



&lt;br /&gt;• Bone offering — casting Summon Skeleton near a Bone consumes it for +10% Max Health and Armor Durability 10%



&lt;br /&gt;



&lt;br /&gt;• Offense — Dark Bolt, Death Touch, Corpse Burst, Black Sepulchre



&lt;br /&gt;



&lt;br /&gt;• Defense &amp; support — Bone Ward, Death’s Blessing, Essence Leech



&lt;br /&gt;



&lt;br /&gt;• Curses &amp; zones — Grave Blight / Withering Curse stacking and detonation (area scales with Magic Power, applies Blind, shows gas)



&lt;br /&gt;



&lt;br /&gt;• Passives — Immortality, Mastery of Binding, Blooming Madness



&lt;br /&gt;



&lt;br /&gt;• Summon gear enchants — gear bonuses that empower Skeleton, Resurrection, and Wraith summons



&lt;br /&gt;



&lt;br /&gt;• Treatises — Necromancy skill books (lootable, including witch-house container chances)



&lt;br /&gt;



&lt;br /&gt;• XP from summons — kills by your thralls credit the player



&lt;br /&gt;



&lt;br /&gt;• Tier 3 / 4 gates — Level 16 / 22 or attribute thresholds

&lt;br /&gt;[b]  Requirements[/b]



&lt;br /&gt;



&lt;br /&gt;• Stoneshard 0.9.4.x on Steam modbranch



&lt;br /&gt;



&lt;br /&gt;• ModShardLauncher Enhanced (https://www.nexusmods.com/stoneshard/mods/103) — recommended / required for current builds



&lt;br /&gt;



&lt;br /&gt;• .NET Desktop Runtime 10.0 for MSL Enhanced (or .NET 6.0 if using older upstream MSL)



&lt;br /&gt;



&lt;br /&gt;• No other content mods required (compatible with other MSL mods in principle; load order / conflicts not guaranteed)
